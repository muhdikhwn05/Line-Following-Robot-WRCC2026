# WRCC Line-Following Robot 🏎️
**Team OneSim** (Wan & Wasim)

A custom-designed line-following robot built for the World Robotic Competition Center (WRCC) 2026. This repository contains the EasyEDA hardware design files

## 🛠️ Hardware Architecture
The custom 2-layer PCB ("Line Following Robot PIRC 26") was designed in EasyEDA to cleanly route logic and power. It integrates the following core components:

* **Microcontroller:** Arduino Nano
* **Motor Driver:** TB6612FNG motor driver IC
* **Actuators:** Dual N20 DC Motors (Left and Right drive)
* **Sensor Array:** HY-S301 IR Sensor module (utilizing analog A0-A7 and digital pins for high-resolution tracking)
* **Power Management:** 2x 18650 lithium-ion battery regulated by a Mini360 step-down converter
* **Onboard Interface:** Main power switch, 3 tactile control buttons, and dual LED status indicators
